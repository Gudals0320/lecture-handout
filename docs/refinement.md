# 녹취록 후처리

이 단계에서만 `prompts/audioscript-refiner-1.5.3.md`를 읽고 실제 입력 TXT 전체에 적용한다. 프롬프트 원문을 교정 대상에 섞지 않는다. 원본은 input에 보존하고 결과는 work/transcript.md에 저장한다.

- STT 교정과 H2 최소 구조화를 수행한다. 강의 정보를 요약·축약·새 설명으로 대체하지 않는다.
- 입력 언어, 기술 수치·조건·예외·설명 흐름을 보존한다. 원문에 근거 없는 사실이나 시간을 생성하지 않는다.
- 타임스탬프가 있으면 의미 구간별 확인 가능한 범위만 사용한다. 없거나 일부만 있으면 확인 가능한 정보만 남긴다.
- 긴 입력은 문맥이 이어지는 단위로 나누어 처리하되 순서·누락·중복을 확인한 뒤 합친다.
- 이미 후처리된 Markdown은 다시 Refiner에 통과시키지 않는다. 기존 삽입 이미지는 합본 단계와 구분하여 검토한다.

## 영어 강의

영어 raw-transcript는 같은 프롬프트로 교정해 `work/transcript-en.md`에 저장하고 `output/<강의명>-EN.md`로 출판한다. 이를 한국어로 번역한 `work/transcript.md`를 `output/<강의명>.md`로 출판한다.

- 번역본은 H2 제목 구조·타임스탬프·수식을 EN과 일치시키고, 전문용어와 영어 고유명사는 영어로 유지한다.
- 이미지는 KR 문서에만 넣는다. mapping의 EN 문서는 `sections: []`로 함께 기록해 재출판에서 빠지지 않게 한다.
- 출판 전 EN·KR의 H2 수, 타임스탬프, 수식 목록이 같은지 검증한다.

공용 스크립트는 LLM 교정을 했다고 가장하지 않는다. `prepare`가 refine_transcript를 남기면 작업 에이전트가 이 단계를 수행하고 다음으로 진행한다. 자동 API 호출은 별도로 요청된 경우에만 구현한다.
