# PDF 처리

PDF의 실제 페이지를 전체 화면 PNG로 렌더링한다. 내장 사진만 추출하면 글자·벡터 도표·필기가 빠질 수 있으므로 그렇게 처리하지 않는다. 보이는 주석과 추가 답안을 포함한다.

- PDF만 제공된 작업에서는 모든 실제 페이지를 연결한다. 표지·목차·구분·퀴즈·마무리 페이지도 포함한다. 사용자가 부분 사용을 명시하면 그 지시가 우선한다.
- MP4/캡처 PNG와 함께 제공된 참고용 PDF는 슬라이드 구조 확인에 쓴다. 자동으로 전체 페이지를 본문에 삽입하지 않는다.
- 물리적 페이지 번호는 1부터 센다. 인쇄된 슬라이드 번호가 뛰더라도 제공되지 않은 페이지를 창작하거나 누락으로 단정하지 않는다.
- 기본 PNG 최대 변은 2400픽셀이다. 작은 코드·수식이 불분명하면 --width를 높인다.
- 페이지는 work/pdf-pages에 보존하고 최종적으로 사용하는 이미지를 output/images로 복사한다. 동일 PDF와 해상도의 정상 파일은 재사용한다.
- mapping의 pdf_coverage에 모든 input PDF의 all 또는 selected 정책을 선언한다. all에서는 모든 페이지가 output 링크 집합에 포함되어야 한다. selected에는 사용자 요구나 참고 교안/공유 강의의 이유를 기록한다.
- 전체 사용을 요구받았는데 본문에 직접 대응되지 않는 페이지는 가장 관련 있는 도입·정리 H2에 배치하고 이유를 남긴다. 자동으로 버리지 않는다.
